Installing (Linux)



git clone https://github.com/littlevenomm464/phphunter.git


cd phphunter


chmod +x phphunter.py


sudo cp phphunter.py /usr/local/bin/phphunter


sudo chmod +x /usr/local/bin/phphunter


sudo ln -sf /usr/local/bin/phphunter /usr/local/bin/hunt



python3 -m pip install curl_cffi --break-system-packages



Usage:



hunt https://example.com
